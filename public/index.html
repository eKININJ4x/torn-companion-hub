Set up TC OC in Torn PDA
  1. Open Torn PDA → Settings → Advanced browser settings. Enable custom user scripts and open Manage scripts / Userscripts.
  2. Open this hub inside Torn PDA’s built-in browser and tap Install TC OC in Torn PDA. Torn PDA will open its script installation screen. Confirm installation and ensure the script is enabled.
  3. If no install prompt appears, use Copy script for Torn PDA below. In Manage scripts, tap +, paste the complete script and save it. Choose injection at End if the panel does not appear.
  4. In Torn PDA’s browser, open Torn → Faction → Organised Crimes. Open the TC OC / OC Utility Manager button.
  5. In TC OC, tap API key, enter your Torn key, then Save API key and Refresh. Private faction data requires the appropriate key permissions and Faction API Access for your faction role.

TC OC runs inside Torn and stores its own key. The hub’s shared key does not automatically transfer into Torn PDA’s userscript. Keep only one copy of TC OC enabled; reload the faction page after installing.
