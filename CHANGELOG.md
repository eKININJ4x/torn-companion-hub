# Torn Companion Hub changelog

## v1.0.0 — 11 October 2026

First stable unified hub release. The owner confirmed that the tools and recent changes were tested and working before this release tidy-up.

- Education, Faction Armoury and War Payouts share one hub API key.
- Unified TC branding, artwork, favicons and navigation back to the hub.
- Education manual progress, modifiers, estimates and saved selections restored; API and manual progress kept separate.
- Courses expand in place. Subjects include code abbreviations and completion checkboxes with partial states.
- Interactive roadmap opens outside the hidden legacy container and has initialized catalogue maps.
- Theme selector moved to the top. Study recommendations link to course details and Torn Education.
- TC OC 1.0.3 highlights the required armoury category in green.
- Torn PDA tap-to-install button serves the canonical script with JavaScript headers; desktop installation and copying remain available.
- Added hourly checks for newer canonical TC OC releases, with version, metadata and syntax validation before updating the hosted installer.
- Added bug-report and feature-request forms. Future features will be chosen after reviewing feedback.

Hub release numbers are separate from Education Companion and TC OC version numbers.
